# FitLife
1. Данный проект позволяет на основе веса и роста определить индекс массы тела
и подобрать ежедневную норму потребления воды.
2. Что бы запустить - необходимо запустить файл fit_life.py при помощи
интерпретатора python (рекомендуемая версия - 3.14).

Был создать Машаровым В.В. по заданию Яндекс.Практикум.
